# Project-Greedy-Fractional-Knapsack
เป็นโปรแจคที่จัดทำขึ้นเพื่อใช้แก้ปัญหา การขนผลไม้ไปขายที่ตลาด สำหรับปัญหา Fractional Knapsack: มีผลไม้ 5 ชนิด แต่ละชนิดมีน้ำหนักทั้งล็อตและกำไรทั้งล็อต รถบรรทุกได้ไม่เกิน W กิโลกรัม และผลไม้แบ่งซื้อเป็นเศษส่วนได้ เป้าหมายคือเลือกให้กำไรรวมสูงสุดโดยไม่เกินความจุรถ
